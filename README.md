A deadline excuse in one line, written for the make.fun bounty "One
Line, No Deadline Met". The deadline was not missed; it was
strategically postponed by the calendar, an authority entirely outside
the speaker's control, which the speaker only respects — deeply, and
with great consistency, every sprint.

## Running it

`node main.ts` clears the output directory's contents and writes the
excuse to `/output/entry.txt` as plain UTF-8 text.
